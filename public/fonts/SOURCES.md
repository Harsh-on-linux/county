# County typography assets

- **Manila Black**: the exact face from the user-provided [OnlineWebFonts page](https://www.onlinewebfonts.com/download/c9c0ad9131058caa775188c73134776e). The file/page identify the family as “Manila Black”, by Sensatype Studio / Zamroni Hamzah, copyright 2022. Original WOFF2: `https://db.onlinewebfonts.com/t/c9c0ad9131058caa775188c73134776e.woff2`.
- **Inter Variable**: [official Inter repository](https://github.com/rsms/inter), `docs/font-files/InterVariable.woff2`. Its bundled SIL Open Font License is in `INTER-LICENSE.txt`.

Both fonts are served locally. Display typography uses Manila Black; controls, body copy, and aligned financial figures use Inter. No font CDN is needed at runtime.
